# Balance implementation verification

Implemented the approved holistic balance proposal with the user's Frangible
exception: preserve stock Rattler accuracy and damage at medium range, add only
a close-range bonus. Player and bot health both present as100; internal durability
is200/90 and weapon damage is shared. See `docs/weapon-balance.md` for the rules.

## Automated verification

- All64 commands in the repository's main regression script passed. This includes
  native combat, feeds, payloads, mobile controls, shop/save progression, scoring,
  recaps, character/weapon presentation, map loading, traversal and source combat.
- `tests/damage-breakpoints.mjs` includes `tests/balance-v2.mjs`, exercising all96
  action/ammunition combinations through the native ballistic resolver. The
  strongest complete fixed sequence is175.5internal damage, equivalent to87.75
  displayed player health. Continuous fire and unintended collateral are separate
  threats; the test does not claim universal immunity to fast deaths.
- Native two-opponent scheduling confirms heavy windup and inter-attack spacing.
  Coordinator tests include per-target limits and in-flight reservations retained
  after shooter death. Rival tests verify25rounds of finite-wallet purchases.
- Normalized health/armor/HUD, actual-damage assist credit, healing caps, legacy
  perk migration, committed bursts, Frangible range parity, delayed barrage,
  Airstrike warning/overlap and nonrecursive streak rewards pass.
- Explosive auto-fire rejects empty-air near misses and accepts a real detonation
  surface. Removing explosive ammunition restores the direct-hit requirement.
- The production build succeeds. Static-release tests confirm all20maps load
  exclusively from production files and exact archives remain intact. Temporary
  browser QA fixtures were removed before the final build.
